## 上位机简明操作手册

1. **启动和连接**　按 [I²C 工程](<02_TargetCarrier -geek-I2C/README.md>) 核对接线及 [配套固件](<02_TargetCarrier -geek-I2C/当前交付.md>)。下载并解压 [控制台 7.0 Windows 运行包](05_上位机/项目资料/程序/控制台7.0/Windows.zip)，运行 `TargetCarrier-7.0.exe`。在控制页搜索 BLE 设备，或选择 GEEK 的 USB 端口。到「设备总览」查看连接状态。
2. **操作 X 轴**　进入「X 轴控制」，确认停止且限位已释放。设置速度和加减速度，选择点动、持续正反转或交替运行。普通停机可用「减速停止」。
3. **操作靶车**　进入「靶车控制」，确认处于运动模式。读取电机配置，在失能状态应用增益，再点击「解除急停」「使能靶车」。收到使能反馈后，设置偏航速度并点击「连续旋转 / 更新转速」。
4. **操作灯光**　在侧栏切换「灯控模式」，等待靶车停止并失能，再选择颜色或红蓝循环。切回运动模式后，重新手动使能才可运动。
5. **停止设备**　按 `Esc` 或点击「全部停止」，查看两台设备各自的停止反馈。

并行程序、SD 录波和连接诊断见 [上位机使用说明](05_上位机/项目资料/使用说明.md)。

仓库同时保留 [6.9 的 Windows 运行包](05_上位机/项目资料/程序/当前版/Windows.zip)及原交付文件。也可按[上位机当前源码说明](05_上位机/项目资料/源码/当前版/README.md)自行构建控制台 7.0。
