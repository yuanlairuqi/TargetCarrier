# I²C 当前交付

以下路径用于查找本机交付。仓库中的[当前上位机源码](../05_上位机/项目资料/源码/当前版/)可构建统一控制台。

| 设备 | 当前交付 | 来源 |
|---|---|---|
| Windows 上位机 | `../05_上位机/项目资料/程序/当前版/` | X4000，包含靶车 ±900°/s 与再使能修复 |
| X 轴 STM32 和 ESP | `x轴/交付文件/当前版/` | X4000，连续模式上限 4000 Hz |
| 靶车 STM32 和 ESP | `靶车/交付文件/当前版/` | 900°/s 版，包含再使能修复和装甲板灯控 |

两个 STM32 镜像可选用对应的 HEX 文件。如果使用 BIN，起始地址为 `0x08000000`。各 ESP 的地址和文件名见各自目录内的 `flasher_args.json`。

## 版本沿革

1. 2026-11-12 装甲板灯控版。原包提供 Windows 程序和日志。
2. 2026-11-13 侧栏灯控版。灯控进入主界面，新增红蓝循环。原包提供 Windows 程序和日志。
3. 2026-11-14 再使能修复版。靶车 STM32 在当前位置建立保持，清除旧运动目标。固件和源码差异归入`靶车/交付文件/历史/`。
4. 2026-11-14 900°/s 版。提高靶车手动连续旋转上限。该包的两块靶车固件仍为当前版，上一版 Windows 程序归档。
5. 2026-11-15 X4000 版。提高 X 轴频率上限，交付 X 轴两块板的固件和新版 Windows 程序。此包的固件用于 X 轴。

四个旧版的 Windows 程序见`../05_上位机/项目资料/程序/历史/`。各处的 `原包-SHA256SUMS.txt` 使用解压包原始相对路径，查找时按本页的路径分配。现有工程源码已包含 X4000 和 900°/s 源码变更。本次为交付归档与入口整理。
