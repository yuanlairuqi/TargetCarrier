|---|---|---|
| Windows 上位机 | [Windows.zip](../05_上位机/项目资料/程序/当前版/Windows.zip) | X4000，包含靶车 ±900°/s 与再使能修复 |

打开 Windows 压缩包后将 EXE 和 `_internal` 一起解压。使用 STM32 的 BIN 文件时，Flash 起始地址为 `0x08000000`。

X 轴和靶车的 ESP 目录包含引导程序及分区表。带现场配对值的 ESP 应用保存在本地。要从源码构建 ESP，请参照 [I²C 工程构建说明](README.md) 及 `tools/build_wired.py`，使用 `x-esp` 或 `target-esp` 作为构建目标。

## 版本沿革

1. 装甲板灯控版加入靶车灯控。
2. 侧栏灯控版将灯控移到主界面并加入红蓝循环。
3. 再使能修复版让靶车 STM32 在当前位置建立保持并清除旧运动目标。[历史固件与源码差异](靶车/交付文件/历史/20261114-再使能修复版/)
4. 900°/s 版提高靶车手动连续旋转上限，仍是当前靶车固件。
5. X4000 版提高 X 轴连续模式频率上限，更新 X 轴固件和 Windows 程序。
