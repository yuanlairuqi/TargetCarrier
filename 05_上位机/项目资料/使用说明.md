# 上位机怎么用

打开 [控制台](../00_上位机合集说明.md)，推荐搭配 [I²C 固件](<../../02_TargetCarrier -geek-I2C/当前交付.md>)。在控制页选择 BLE 直连设备，或通过 USB 选择 GEEK 总机。

| 入口 | 操作 |
| --- | --- |
| 设备总览 | 查看两台设备的连接和停止状态 |
| X 轴控制 | 设置速度及加减速度，选择点动、持续或正反交替 |
| 靶车控制 | 确认停止后解除急停、手动使能，再发送旋转指令 |
| 侧栏装甲灯控 | 靶车停止并失能后切换至灯控模式，再设置颜色 |
| 并行程序 | 各自编排两台设备的动作和等待 |
| 实时数据与录波、连接诊断 | 操作 GEEK SD 录波，或查看连接状态与日志 |

需要同时停止两台设备时，点击「全部停止」或按 `Esc`。
