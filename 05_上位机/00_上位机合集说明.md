# TargetCarrier 上位机

[当前源码](项目资料/源码/当前版/)内的 `build-unified.ps1` 用于构建 Windows 上位机。[历史源码](项目资料/源码/历史/)保留 6.0 双从机版、6.1.3 诊断版和手动 360 版。

树状图展示本机目录。仓库提供源码、文档、Windows 压缩包和 STM32 固件。本机快捷方式、现场日志和带配对信息的 ESP 应用保存在本地。

## 6.9 后续源码

当前源码提供互斥的靶车运动和灯控模式。切换灯控时，上位机先请求停止及失能，收到反馈后开放灯控操作。切回运动时结束循环，后续运动需手动使能。使用当前源码的 `build-unified.ps1` 可构建对应程序，上方 Windows 下载仍指向原交付版本。
