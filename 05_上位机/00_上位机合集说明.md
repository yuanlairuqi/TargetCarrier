# Windows 上位机

- **靶车上位机**　下载并完整解压 [控制台 7.0 Windows 运行包](项目资料/程序/控制台7.0/Windows.zip)，双击 `TargetCarrier-7.0.exe`。
- **通用调参**　双击 `启动通用调参.lnk`，配合 [TC/2 固件](<../02_TargetCarrier -geek-I2C/portable_comms/README.md>) 使用。
- **项目资料**　`程序/` 放运行包，`源码/` 放控制台源码，`历史日志/` 放旧日志。运行包的 EXE 与 `_internal` 放在一起。

日常搭配 **I²C 版**。[使用说明](项目资料/使用说明.md) · [当前源码](项目资料/源码/当前版/README.md) · [历史文件](项目资料/历史版本索引.md)

公开仓库提供[控制台 7.0 源码和构建入口](项目资料/源码/当前版/README.md)。运行 `TargetCarrier-7.0.exe` 时保留同目录的 `_internal`。
