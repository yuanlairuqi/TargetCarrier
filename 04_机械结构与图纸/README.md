# 靶车机械结构与图纸

TargetCarrier 靶车的机械结构开源资料：SolidWorks 原生模型（28 个零件、4 个装配体）与两份技术文档。固件与上位机见仓库根目录 [README](../README.md)。

## 机构概要

靶车提供两个自由度：

- **X 轴**：导轨与滚轮式行走机构，双同步带传动，57 步进电机驱动；
- **旋转靶台**：靶面绕垂直轴旋转，57 步进电机驱动，线缆经滑环引出。

## 目录

| 文件 | 说明 |
| --- | --- |
| `靶车/靶车总装.SLDASM` | 完整总装，含导轨、X 轴传动与旋转靶台 |
| `靶车/靶车总装（实际长度）.SLDASM` | 按实际铝型材下料长度修正的总装 |
| `靶车/装配体靶车主体.SLDASM` | 靶车主体子装配 |

| `TargetCarrier靶车系统开源报告_技术文档（结构与器件说明）.docx` | 机械结构、传动选型对比、器件清单、装配与调试 |
| `靶车/TargetCarrier靶车系统开源报告_技术文档（完整版）.docx` | 在上一份基础上补充硬件接线、软件设计、通信、使用与验证情况 |

两份文档由同一份报告拆分而来：「结构与器件说明」聚焦机械，「完整版」覆盖结构到上机使用的全过程，按需取用。

## 打开方式

用 SolidWorks 打开任一 `.SLDASM` 总装。零件与总装之间使用相对路径引用，保持本目录结构完整即可正常解析，不要单独移动 `.SLDPRT`。

仓库未附 STEP/STL 中间格式；若只需查看或跨软件使用，从总装导出即可：

> 文件 → 另存为 → STEP AP214（`.step`）

## 说明

- 零件命名沿用设计阶段的叫法。其中 57 步进电机、LMT 梅花联轴器、RM 装甲板、rm 开发板、2GT 同步带轮等为外购件或第三方模型，仅用于装配校核，采购型号以技术文档中的器件清单为准。
- 图纸处于设计交付状态，未做加工艺审查；下料、折弯、攻丝、表面处理等请按实际工艺复核后再投产。
