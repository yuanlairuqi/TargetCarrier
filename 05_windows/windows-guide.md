# Windows 上位机

- **靶车上位机**　运行 [7.0 安装程序](TargetCarrier-Setup.exe)。安装后从开始菜单打开 TargetCarrier 7.0。
- **通用调参**　从控制台或开始菜单打开 TC-Portable，配合 [TC/2 固件](<../02_TargetCarrier -geek-I2C/portable_comms/README.md>) 使用。
- **项目资料**　`project/source/` 放控制台源码，`project/programs/legacy-x4000/` 保存原 X4000 程序。7.0 运行日志位于 `%LOCALAPPDATA%\TargetCarrier\logs`。
