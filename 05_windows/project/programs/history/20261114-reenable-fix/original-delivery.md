# TargetCarrier I²C 靶车再使能修复

- `Windows/` 是完整的便携上位机。解压整份目录，保留 `_internal`，运行 `TargetCarrier-I2C-Armor.exe`。
- `STM32/` 是靶车 STM32F103C8T6 固件。配套上位机要求能力码 `0x00060102`，旧版能力码会阻止使能。烧录地址按原工程的 `0x08000000`。本次交付未烧录。
- `Source/` 是按原桌面工程相对路径放置的 20 个变更文件，已回写并逐一校验哈希。`source.patch` 记录从原桌面源码到新版本的差异。`SHA256SUMS.txt` 可校验程序、固件及源码。

STM32 使用最新的原始 CAN 位置码建立就地保持目标。零位置增益、零速度目标及零力矩前馈的 MIT 帧先发，CAN 确认后再发 ENABLE。新的电机反馈确认使能后，保持增益才开始爬升。再使能要求 50 ms 内的失能反馈及不超过 0.05 rad/s 的速度。等待确认或就地保持时，偏离初始位置超过 0.02 rad 会撤销授权。已经确认使能且收到本周期的新运动命令后，才恢复原有运动增益斜坡和轨迹控制。

离线验收通过 310 项上位机测试和 5 组 CTest，包含全部 65,536 个 MIT 位置码的折叠量化测试、真实控制循环的模拟 CAN 发送、过期反馈、急停、失能后立即再使能与旧运动帧。Windows 打包后 GUI 自检通过。现有桥接透传由关联聊天独立复核。

实机验收需要记录重新使能前后的原始位置、首批 CAN 帧、驱动故障码、母线电压和峰值电流。量程边界、正反转后的停车再使能都需要验证。旋转中途因 BLE 或 I²C 调度触发停机的问题仍待修复。
